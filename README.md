# Игра в кости из книги "Цель"

Симуляция производственной линии с зависимыми этапами, описанная в книге Элияху Голдратта "Цель".

## Описание

Игра демонстрирует два ключевых принципа теории ограничений:

1. **Зависимые события** — каждый рабочий в производственной линии зависит от предыдущего: он не может передать больше, чем получил.
2. **Статистические флуктуации** — производительность каждого рабочего варьируется (бросок кубика 1-6).

### Что показывает симуляция

Несмотря на то, что средняя производительность одного рабочего равна 3.5 (среднее от 1 до 6), фактическая пропускная способность всей линии всегда **ниже** ожидаемой. Это происходит потому, что:

- Простой одного рабочего накапливается в виде незавершённого производства
- "Узкое место" в любом месте линии ограничивает общую производительность
- Потери от флуктуаций не компенсируются в следующих раундах

## Запуск

```bash
dotnet run
```

При запуске предлагается выбрать режим:
- **Быстрый** — все раунды выполняются сразу
- **Интерактивный** — каждый раунд по нажатию Enter

## Настройка

Параметры игры задаются в файле `appsettings.json`:

```json
{
  "workers": 5,
  "rounds": 10
}
```

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `workers` | Количество рабочих в линии | 5 |
| `rounds` | Количество раундов | 10 |

## Вывод

После завершения игры отображаются:
- Общее количество выпущенной продукции
- Среднее значение за раунд
- Ожидаемое среднее (3.5 × количество раундов)
- Эффективность системы в процентах

## Пример вывода

```
=== Итоги ===
Итого выпущено: 17
Среднее за раунд: 1,70
Ожидаемое среднее (3.5 * 10): 35,00

Эффективность: 48,6%
```
